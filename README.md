# Online Retail Dashboard (DAV Seminar Activity)

Streamlit dashboard answering the pre-seminar questions on the Online Retail dataset:
total sales, unique orders, best month, top 5 products and top countries.

## Run
1. Put `Online_Retail.xlsx` in this folder (not tracked in git).
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

The first run reads the Excel file (about a minute) and caches it as `Online_Retail.pkl`.
